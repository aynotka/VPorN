## Как установить

**Android.** Скачайте `VPorN.apk`, откройте файл и разрешите установку из этого источника, если телефон спросит. Запустите приложение и нажмите большую кнопку.

**Windows.** Скачайте `VPorN-Setup.exe` и запустите. Если появится «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Приложению нужны права администратора: без них Windows не даёт создать VPN-подключение.

**iPhone / Mac.** Откройте бота [@VPN_panel_h1cloud_bot](https://t.me/VPN_panel_h1cloud_bot), нажмите «🔐 Получить VPN» → «🚀 Открыть в Happ» или «🚀 Открыть в V2Box».
